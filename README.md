# QNOVA 교재 편집기 — 배포 저장소

HWP · DOCX · PDF에서 필요한 페이지만 골라 하나의 교재 PDF로 만드는
Windows 무료 프로그램입니다.

## 다운로드
https://editor.qnova.co.kr/download

## 이 저장소에 있는 것
- `app-config.json` — 앱이 조회하는 공지 · 업데이트 정보
- `download/` — 다운로드 안내 페이지
- Releases — 설치 파일(.exe)

앱 소스코드는 포함되어 있지 않습니다.
